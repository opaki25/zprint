# Kiosk portal — Phase 4

Reserved for the React kiosk client. Use the same sessions/documents/quotes/jobs APIs with source USB. Required before claiming kiosk support: approved USB-root enumeration, safe isolated import, no general OS file browser, safe eject, inactivity reset/wipe, fullscreen restricted OS account, disabled autorun/system shortcuts and physical controls. No kiosk lockdown is implemented in Phase 1.
