- [ ] Provision OS kiosk account, safe USB importer, inactivity cleanup, enclosure and UPS.
- [ ] Validate offline local API, Wi-Fi access, sync conflicts/duplicates and no unverified offline payments.
- [ ] Implement operator review/reprint/refund without duplicate side effects.
- [ ] Test retention, transaction backup restoration, alerts and privacy/support policy.
- [ ] Run real jams, out-of-paper, uncertain restart, network outage, queue backlog and 100+ page monitored scenarios.
